## Objetivo y procedimiento

Convertir la línea base del primer avance en una especificación verificable siguiendo la estructura de IEEE 830. Se compararon las tablas de las pp. 6–7 con el código, se fijaron los criterios y se vincularon casos de prueba. El modelo de proceso es iterativo: elicitación y revisión, decisión, implementación aislada y retroalimentación de pruebas.

## Cuestionario

- **Fuentes comunes.** Entrevistas, observación de operaciones, documentos de trabajo, talleres y sistemas existentes. En AgroRetorno, el primer avance, el código y las pruebas sirven como fuentes documentales.
- **Entrevistados.** Se elige a quien conoce la decisión o la operación. Además de usuarios finales, puede participar el responsable del almacén, operaciones o un cliente representado.
- **Cuestionario y encuesta.** El cuestionario es el instrumento y la encuesta es el proceso de aplicación y análisis. Para comparar respuestas de varios roles se usa un instrumento uniforme. Para entender una causa o resolver un desacuerdo se combina con entrevista.
